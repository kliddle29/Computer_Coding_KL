Test 01

Sigil seed

Tests Law 1: the sigil's geometry is generated once from one rule, a jittered icosahedron, and never edited after that. Click the canvas to run the rule again and produce a new instance. The first pass used a wide jitter range and the results read as random blobs rather than one family; narrowing it to roughly ±15% of the base radius kept every instance legibly the same sigil.

Test 02

Behavior rule

Tests Law 4: a streamline approaching the fixed circle is pushed outward under one proximity rule, structured like Cubic Disarray, one rule applied with increasing force row by row. Here the rule is deflection instead of rotation. No input drives this test on purpose, it's checking whether the rule alone reads clearly. The top row's deflection was nearly invisible on the first run, which looked like a bug rather than a gradient, so a minimum deflection floor was added until even the faintest row still visibly bends.

Test 03

Gesture language

Tests the gesture from Q06: horizontal drag maps to exactly one parameter, camera yaw, and nothing else. The object holds still until touched, unlike Test 1's ambient rotation, so every bit of motion on screen is caused by you. The first pass also mapped vertical drag to pitch, but that made the one-parameter claim untrue, so pitch was cut and the gesture was reduced to the single axis the proposal actually commits to.

Test 04

Atmosphere constraint

Tests one atmospheric constraint: depth fog. Each element's color blends toward the background as a function of its real distance from the camera, not a painted-on vignette. No user input drives it, distance is the only variable; the checkbox merely toggles it on and off for comparison and isn't part of the system itself. Without fog every particle read at equal weight regardless of depth, which flattened the orbit from Test 3, so the depth-based fade was added to restore a sense of distance without introducing any new color or shape.
